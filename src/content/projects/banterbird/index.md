BanterBird is a Chrome extension that helps you write better replies on X (Twitter). Using your own OpenAI API key, it drafts a suggested reply to any post — then you review, edit, and post it yourself. It's a writing assistant, not automation: no bots, no bulk posting, you stay in control of everything that goes out.

Hit a keyboard shortcut on any post, get a draft, tweak it, and ship it. Learn more at [banterbird.com](https://banterbird.com).
